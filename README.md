# KCSTARIFF — 한국 HSK 10단위 관세율 DB (2007~2026)

관세법령정보포털(CLIP)이 화면으로만 보여 주는 연도별 HSK 10단위 세율을 스무 해 전부 받아 DuckDB 한 파일로 만든 것이다. 기본세율·WTO 협정세율·탄력세율(조정·할당·특별긴급·덤핑방지)·농림축산물 양허세율과 FTA 일곱 상대(중국·EU·미국·아세안·인도·베트남·캐나다)의 협정세율이 코드×연도×세율 구분으로 들어 있고, 연중에 바뀐 세율은 적용 기간으로 나뉘어 있다. 여기에 관세법 제50조의 우선순위와 FTA 관세특례법 제5조를 조문대로 옮겨 코드×연도마다 실제로 적용되는 한 값(실행세율)을 원산지별로 계산한 파생표를 더했다.

무역통계 DB [KCSDB2](https://pilsunchoi.github.io/KCSDB2/)와 연도·HS10으로 바로 조인된다.

> **고지.** 포털은 10단위 세율이 참고용이며 법적 효력이 없다고 밝힌다. 실행세율은 이 저장소가 조문을 해석해 만든 파생값이다. 세액 계산이나 신고에는 관세법 별표와 해당 규정의 원문을 확인할 것.

## 무엇이 들어 있나

|---|---|---|

세율 구분 24종: 기본 A, WTO C, 개도국 D·G1·G2, 아시아태평양 E1~E3, 국제협력 F, 덤핑방지 I(2016~), 조정 L, 할당 P1·P3, 특별긴급 T1·T2, 농림축산물 양허 W1(추천)·W2(미추천), FTA FCN1·FEU1·FUS1·FAS1·FIN1·FVN1·FCA1.

## 실행세율을 만드는 규칙

관세법 제50조와 FTA 관세특례법 제5조, 양허관세 규정 제6조를 조문대로 옮겼다(원문은 `docs/실행세율_법령근거.md`).

- 무협정 세율 = 할당관세 P3가 있으면 P3, 아니면 조정관세 L, 아니면 기본세율 A. WTO 협정세율 C와 국제협력관세 F는 그보다 낮을 때만 우선한다(제50조③ 본문). 농림축산물 양허세율 W2는 기본세율보다 높아도 우선하되(③ 단서) 할당관세가 있으면 할당관세를 따른다.
- FTA 협정세율과 아시아태평양 협정세율은 무협정 세율보다 낮을 때만 적용한다(특례법 제5조①). 중국·인도는 FTA와 아시아태평양 협정 중, 베트남은 FTA와 아세안 중 낮은 쪽이다.
- 덤핑방지·특별긴급·추천이 필요한 할당·양허 세율은 원산지나 물량 조건이 붙으므로 표시만 하고 실행세율에 넣지 않는다.
- 연중 변경은 유효 일수로 가중평균하고(`mfn`, `applied_*`) 1월 1일 값을 따로 둔다(`mfn_jan`).
- "270% 또는 kg당 6,210원"처럼 높은 쪽을 적용하는 선택 세율은 종량세를 종가세율로 나눈 값을 종량 하한(`floor_won_kg`)으로 둔다.
- 세율이 하나로 정해지지 않는 코드는 미확정으로 표시한다. 종량세만 있는 코드(영화필름), 두 별표에 함께 오른 코드(인삼 기타), 관세화 전의 쌀(2007~2014).

## 받기와 사용

DB 파일(약 37MB)은 Releases에서 받는다. 저장소에는 없다.

```python
import duckdb
con = duckdb.connect("kcstariff.duckdb", read_only=True)
con.sql("SELECT * FROM fct_applied_rate WHERE hs10='0904210000' AND year=2025").show()
```

무역통계와 함께 쓰려면:

```python
con = duckdb.connect()
con.execute("ATTACH 'kcsdb.duckdb' AS s (READ_ONLY)")
con.execute("ATTACH 'kcstariff.duckdb' AS tr (READ_ONLY)")
con.sql("""
SELECT f.yyyymm, f.stat_cd, f.hs10, f.imp_dlr, r.mfn, r.applied_cn
FROM s.fact_trade f JOIN tr.fct_applied_rate r ON r.year = f.yyyymm//100 AND r.hs10 = f.hs10
WHERE f.hs10 = '0904210000' AND f.yyyymm >= 202401""").show()
```

## 다시 만들기

```bash
python scripts/01_fetch_tariff.py            # 두 화면을 류 단위로 받는다(연도당 97회×2, 스무 해 약 1시간 반). 캐시가 있으면 --parse-only
python scripts/02_build_applied_rate.py --load   # 실행세율 파생표를 만들어 DB에 넣는다
```

원본 캐시(약 1.2GB)는 `data/raw/`에 두고 저장소에 올리지 않는다. 캐시를 다른 곳에 두었으면 `KCSTARIFF_RAW`로 가리킨다. 무역통계 DB가 있으면 `KCSDB2_PATH`로 가리켜 수입액 커버리지 검증을 함께 한다.

실행세율에 적용한 조문 원문은 [`docs/실행세율_법령근거.md`](docs/실행세율_법령근거.md)다.

## 검증

- 두 화면(관세율표·주요세율보기)의 코드 집합이 해마다 한 개만 다르고, 기본세율 99.80%·WTO 세율 99.97%가 일치하며 어긋남은 전부 표기 차이다.
- 알려진 값 8건(건고추 270%, 생강 377.3%, 고추다진양념 조정관세 45%와 한중 44.5%, 냉동고추 27%, 한-EU 7월 인하의 가중평균 등)이 맞는다.
- 일곱 상대의 1월 1일 협정세율을 품목 상세 화면(다른 출처)과 대조한 22,164행이 전부 일치한다.
- 수입액 가운데 그해 실행세율이 있는 코드의 몫이 99.92~100%다.

## 함정과 한계

- 서버가 표를 절반쯤 보내다 오류 안내문으로 끝내면서 상태 코드 200을 주는 일이 있다(2011년 제90류). 스크립트가 문구로 가려내 캐시하지 않고 다른 화면으로 채운다.
- 관세율표 화면은 1월 1일 기준이라 하반기 할당관세 지정 같은 연중 변경을 놓칠 수 있다. 일곱 상대의 협정세율은 적용 기간이 있어 연중 변경이 반영된다.
- 그 밖의 FTA(칠레·EFTA·싱가포르·페루·튀르키예·호주·뉴질랜드·콜롬비아·영국·중미·이스라엘·캄보디아·필리핀·인도네시아·UAE·RCEP)는 품목 상세 화면에만 있어 이 DB에 없다. 2025년 수입액 기준으로 일곱 상대가 59.7%, 그 밖의 협정 상대가 16.7%다.
- FTA 세율은 적용 가능 세율이지 납부 세율이 아니다. 특혜 활용 여부는 관측되지 않는다.
- DuckDB는 표를 갈아 끼워도 파일이 줄지 않으므로 적재는 새 파일에 쓰고 바꿔 끼운다.

## 출처와 이용 조건

세율은 관세법령정보포털(https://unipass.customs.go.kr/clip/)의 관세율표·주요세율보기 화면에서 받았다. 같은 자료를 관세청이 공공데이터포털에 「품목번호별 관세율표」(15051179)로 공개하며 이용허락범위는 공공누리 제1유형(출처표시)이다. 이 저장소의 파생표는 그 자료를 가공한 것이며, 이용할 때 관세청과 이 저장소를 출처로 밝힐 것.
